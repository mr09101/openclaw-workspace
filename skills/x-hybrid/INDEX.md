# X Hybrid Workflow

목표: X(트위터) 링크를 받았을 때 요청 강도에 따라 **LIGHT(단일)** 또는 **PRO(그래프)** 모드로 처리한다.

## Mode Router
- 기본값: LIGHT
- 아래 조건이면 PRO로 승격
  - 사용자가 저장/분류/누적 학습 요청
  - 첨부 미디어 해석 + 외부 아티클 교차확인까지 요청
  - 같은 주제 반복 추적 요청(시리즈/연재/키워드)

## LIGHT
- 빠른 단건 처리
- 파일: [[LIGHT.md]]

## PRO
